# Simple Calculator

A lightweight, terminal-based **Basic Calculator** application built with Python. This project allows users to perform standard arithmetic operations quickly through a clean, interactive command-line interface.

## 🚀 Features

* **Basic Arithmetic:** Supports addition, subtraction, multiplication, and division.
* **Continuous Operations:** Loop functionality allows for multiple calculations without restarting the program.
* **Error Handling:** Built-in safeguards against division by zero and non-numeric inputs.
* **Reset Functionality:** Option to clear the current calculation and start a new one or exit cleanly.

## 🛠️ Tech Stack

* **Python 3.x:** Powers the core operational logic and terminal user interface.

## 💻 Getting Started

Follow these simple instructions to get a copy of the project running on your local machine:

### Prerequisites

Make sure you have Python 3 installed on your system. You can verify this by running:
```bash
python --version
```

### Installation & Execution

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the directory:**
   ```bash
   cd basic-calculator
   ```

3. **Run the application:**
   ```bash
   python calculator.py
   ```

## 🧩 How to Use

1. Run the script to launch the interactive prompt.
2. Select your desired mathematical operation from the menu.
3. Input the first and second numbers when prompted.
4. View the calculated result instantly in the console.
5. Choose whether to perform another calculation or exit the application.
